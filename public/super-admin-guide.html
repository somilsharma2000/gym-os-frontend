As Super Admin, you have full control over the entire Gym OS platform. You can add new gyms, connect integrations, manage all client accounts, and troubleshoot issues.

2. Adding a New Gym

Step-by-Step Onboarding

1

Create Gym Account

Go to Super Admin panel. Click "Add New Gym". Enter: gym name, owner name, owner email, owner phone, gym ID (format: gym_).

2

Set Password

Create a password for the gym owner. Share it with them securely. They can change it later.

3

Seed Data

Run the seed function to create sample members, classes, and trainers so the dashboard isn't empty on first login.

4

Generate Website

Go to Integrations > Website. Click "Generate Website" to create the gym's public-facing website with their branding.

5

Connect WhatsApp

Go to Integrations > WhatsApp. Enter the gym's WhatsApp Business API credentials (WABA ID, Phone Number ID, Access Token).

6

Set Up Payments

Go to Integrations > Payments. Enter Razorpay or Stripe API keys for the gym.

7

Test Login

Switch to the new gym using the gym switcher. Verify the dashboard loads correctly with seeded data.

3. Connecting Integrations

WhatsApp Business API

Required: WABA ID, Phone Number ID, Access Token, Verify Token.

Setup: Meta Business Manager > WhatsApp Manager > API Setup. Copy credentials into Gym OS Integrations tab.

Payments (Razorpay/Stripe)

Required: Key ID and Key Secret (Razorpay) or Secret Key (Stripe).

Setup: Create account at razorpay.com or stripe.com. Get API keys from dashboard. Enter in Gym OS Integrations.

Social Media

Required: Facebook Page ID + Access Token, Instagram Account ID + Access Token, LinkedIn Org ID + Access Token.

Setup: Connect via Meta Business Manager for FB/IG. LinkedIn: Company Page > Admin > API.

5. Common Issues & Fixes

Login Failed

Cause: Wrong credentials or account suspended.

Fix: Check GymAccount entity for the email. Verify password_hash matches. Check status field is "active".

Dashboard Empty

Cause: No seed data for the gym.

Fix: Run seedGymData function with the gym_id. This creates sample members, leads, and classes.

WhatsApp Not Sending

Cause: Missing or expired API credentials.

Fix: Go to Integrations > WhatsApp. Verify WABA ID, Phone Number ID, and Access Token are correct. Re-generate token in Meta Business Manager if expired.

Payments Not Recording

Cause: Payment gateway not connected or API key mismatch.

Fix: Check Integrations > Payments. Verify Razorpay/Stripe keys. Test with a small amount.

Website Not Loading

Cause: Website not generated or gym profile incomplete.

Fix: Go to Integrations > Website. Click "Generate Website". Ensure GymProfile has name, address, hours, and description filled.

403 Error on API Calls

Cause: Token expired or wrong API base URL.

Fix: Check token format (JWT with exp field). Verify function routing in client.ts — GYMOS functions go to GYMOS app, admin functions go to Superagent app.

6. Data Isolation

How Gym Data Stays Separate

Every entity record has a gym_id field. All API calls filter by gym_id. Gym owners are locked to their gym_id. Super admin can switch between gyms.

Never hardcode gym_id in backend functions. Always read it from the request payload.
